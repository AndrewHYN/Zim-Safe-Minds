# Launch and grant readiness — owner checklist

## Ready in code
- Responsive static app and scripted chat; no PHI database.
- Visible urgent-help copy with no unverified hotline numbers.
- Care navigator preferences: format, affordability, language, plus direct public independent-service link.
- Four existing scripted-guide tests plus two care-preference tests; GitHub Actions build required.
- Basic docs for safety, grant application, evidence, pitch and budget.

## Must be done by founder before 20 October
1. Verify actual GitHub preview URL, browser behavior and phone screens.
2. Confirm eligible team lead aged 18–35 ordinarily resident in Zimbabwe; gather factual member roles and contacts.
3. Recruit qualified clinical advisor(s) for a *conversation*, not a fictional endorsement; professional review is essential before any live care rollout.
4. Seek 3–5 initial youth perspectives and one independent professional perspective **if possible**. Only state these took place if they actually did.
5. Copy shorter drafts to the official form; confirm live field limits, submit by 20 Oct 23:59 CAT and save confirmation.
6. Prepare 90-second pitch and screencast before finalist notifications around 23–24 Oct.

## No-go until validated
- Live therapy or clinical assessment
- AI diagnosis, triage or crisis prediction
- Collection of identifiable health data
- Unverified provider profiles
- Claiming government, UN, Friendship Bench or clinician endorsement
- Referrals without consent and signed operating agreements

No published page should imply HackLab selection, award or endorsement.
